# 玩家手册

这条路线面向只想进入比赛、选队、购买装备、战斗或观战的玩家。你不需要了解 Java 或地图文件。

## 进入一场比赛

1. 在客户端打开 FPSMatch 地图选择界面，浏览地图、模式、人数和房间状态。
2. 选择房间查看详情；确认状态为等待中，或模式允许中途加入。
3. 点击加入大厅，选择一个可用队伍，然后点击准备。
4. 等待房间倒计时结束。队伍、准备状态和玩家列表会在房间页面同步更新。

如果界面没有房间，通常是服务器没有加载地图，或没有模组注册可用的游戏类型。请让管理员检查 `/fpsm help` 和服务器日志。

## 对局中你会遇到什么

- 地图和队伍决定出生点、队友标记与可用能力。
- 回合模式会在开始、新回合、玩家死亡、胜利和重置之间切换；死后可能进入旁观流程。
- 支持商店的地图会在购买阶段开放购买界面。商店是否可用取决于当前模式、队伍能力、购买时间和购买区域。
- 旁观者可以使用服务器提供的镜头、队友切换和死亡回放能力；具体按服务器配置显示。

## 商店打不开怎么办

先确认你已经加入地图，游戏已经开始，仍在购买时间和购买区域内，并且当前地图支持商店。若仍失败，请把地图名、模式和界面提示交给管理员；不要反复重连，这不会修复未初始化的商店能力。

## 地图选择界面

地图卡片可能显示图标贴图，详情页可能显示背景贴图。贴图由服务器地图设置提供，但实际资源必须存在于你的模组包或资源包中；资源缺失时会显示色块兜底。

## 你可以向管理员报告什么

报告问题时附上：服务器版本、FPSMatch 版本、游戏类型（例如 `cs` 或 `csdm`）、地图 ID、是否已加入队伍、是否在对局进行中，以及完整的界面提示。这样比只说“进不去”更容易定位。
