## 数据和依赖

新增独立Java17模块 `FPSMatch/editor-platform/storage`。生产依赖仅Gson，公开API仅JDK类型；可脱离Minecraft／loader构建，并作为FPSMatch子项目编译和打包。它管理字节、身份、依赖及提交，不实例化运行地图、不控制世界、不承担扩展模块业务校验。

目录固定为 `CURRENT`、`commits/<commitId>.json`、`documents/<sha256>.blob`、`assets/<sha256>.blob`、`.pending/` 和 `.editor.lock`。恢复记录／派生缓存保留独立职责，本切片不自动生成。路径均由平台身份生成，存档不接收任意持久文件路径。

清单v1记录projectId、commitId、parentCommitId、projectName、modules、documents、assets及可空origin。commitId使用本次requestId，使一次逻辑请求的候选位置稳定；提交身份不是业务内容修订或对象ID。origin记录接收分享副本的直接来源工程与保存版本，不能冒充作者认证。

每项文档／资源有稳定id、ownerModule、typeId、codecId、schemaVersion、displayName、content及documentDependencies／assetDependencies。typeId、codecId、ownerModule为namespaced ID；modules记录已解析的确切模块版本，不在存储层解释版本范围。content含来源类别、固定摘要和长度；平台清单JSON与领域文档自己的JSON／二进制编码独立。这里不新增队伍、出生点、区域等固定字段。

平台元数据用严格UTF-8 JSON，拒重复键、非法Unicode、尾文本、未知外壳字段及不支持的格式版本，保留原文件供检查；领域内容作为不透明原始字节保真，不在此层尝试解码未知模块。上层必须完成模块／codec兼容和领域校验后才允许制作保存；底层能复制原始字节不代表编辑器可以修改缺模块文档。

依赖必须在该工程快照内闭合；本切片不表达跨工程可写事务。引用模组内置资源时由上层的显式依赖适配形成可校验描述，不伪造成已打包的工程资源。资源改名不改变稳定ID；内容改变产生新blob。

## 保存和请求结果

1. 本机文件锁覆盖整个可写会话，同物理目录第二个写者收到BUSY；无多人编辑租约。分享副本不同路径可独立打开。
2. 先流式写blob并强制写文件，再验证所有引用内容，写完整不可变清单。
3. 在锁内重读CURRENT，比较调用者捕获的expectedCommitId与会话打开／最近确认的基线；外部修改阻止覆盖。
4. 新CURRENT包含projectId、commitId、清单摘要和最近64项请求回执。写同目录临时文件、force后执行ATOMIC_MOVE；不降级成逐文件覆盖。
5. 发布前错误不改变正式入口；开始发布后无法核实的错误为RESULT_UNKNOWN。重开后查询原requestId。查询不在保留窗口时为UNKNOWN，不等于失败；旧基线仍阻止盲目重写。

同requestId、同候选重试返回原提交及当前入口；同requestId异内容拒绝。CURRENT及回执一同发布，临时清单存在不等于提交成立。超过回执窗口的请求查询不追溯所有历史，也不自动授重试成功。

正式状态只沿CURRENT加载，不扫描最新mtime或自动启用孤立清单。当前入口或依赖损坏明确报错，旧文件与候选保留；人工恢复功能另行实现，不静默选择较旧版本。首次创建到CURRENT前中断的目录仍为未完成工程。

本实现保证受控写者及已实测文件系统上的进程中断一致性，不宣称掉电耐久或对任意网盘／网络文件系统适用。目录元数据持久保证与目标后端能力另验。未受控外部进程可破坏文件，基线／内容检查用于发现，不能宣传本机文件锁能阻止所有外部写者。

## 分享

分享包是ZIP：`snapshot.json`为选定的完整清单，其他条目仅允许快照实际引用的document／asset blob。导出固定已保存快照；不包含CURRENT回执、全部历史、缓存、恢复点、锁、个人设置或权限。分享导出不改变已保存入口。

导出先在目标同目录完成临时ZIP、force并关闭文件，再以创建硬链接发布完整文件，随后清临时名；目标已存在或同时被另一次导出占用时拒绝，不替换任何既有输出。不能把无REPLACE标志的ATOMIC_MOVE当作不可覆盖保证。文件系统不支持这种发布方式时安全失败，不回退到直接写目标文件。

导入预检重复条目、路径、条目数量、展开容量和依赖闭包；只向新建独立目录写数据，按清单推导允许条目，不执行包内代码。传输内容逐项校验后以新requestId发布本机首次提交，保留project／document／asset身份，origin记录来源commit；不继承对方安装状态或请求回执。

导入失败保留原包和原工程；新目录可能留下可诊断的未完成内容，不能显示成功或自动列为可打开工程。接力回传仍先导入副本，首版整项目选版，不在此模块自动合并。

## 初始预算及边界

默认清单4MiB、CURRENT256KiB、单blob512MiB、工程内容合计16GiB、文档与资源合计8192项、依赖引用合计65536条、字符串4096字符、回执64项。JSON结构另限深度16、值节点262144；保存前按同一读取规则预检，不能发布自身无法重开的清单。预算针对当前引用内容和每次处理，不是历史累计磁盘配额。总元数据预算优先，项数未超不保证清单一定容纳。运行预算可显式收紧或调整，不把这些数值写进业务类型语义；未来更大档位须实测。读写流实际计数，不信任压缩包声明大小。

本切片保留历史及孤立blob，不自动GC；避免误删保存、恢复或分享仍需要的资源。完整保留策略／资源清理UI、存储配额与性能优化另做，尚不能称成熟发布。数据流校验先确保正确，之后才能依据实际耗时优化重复校验。
