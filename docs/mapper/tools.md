# 地图工具

FPSMatch 在创造模式物品栏中提供四种制图工具。工具只是服务端管理界面的便携入口，配置结果仍保存在对应地图中。

## 地图创建工具

物品 ID 为 `fpsmatch:map_creator_tool`。左键方块设置第一端，右键方块设置第二端，`Ctrl + 右键` 打开界面。界面可以创建地图，也可以选择已有地图后更新其区域。

工具保存草稿名称、选中类型、选中地图和两端坐标。关闭界面会保存草稿到当前物品；尚未点击创建的草稿不会出现在地图列表中。手持工具时会持续刷新当前区域预览，换下工具后该预览会被清理。

## 复活点工具

物品 ID 为 `fpsmatch:spawn_point_tool`。`Ctrl + 右键` 打开选择界面，依次选择游戏类型、地图和普通队伍。选中后，对目标地面方块右键会把其上方位置加入该队出生点。

界面可以浏览当前队伍的出生点，删除选中点或清空该队全部点。手持工具时会显示地图边界和所有普通队伍的点位；不同队伍使用不同颜色。

记录的朝向来自玩家添加点位时的 yaw 和 pitch。希望玩家出生后朝向战场入口时，先站在合适位置并看向目标方向，再添加点位。

## 对局配置工具

物品 ID 为 `fpsmatch:match_config_tool`。右键打开设置界面，顶部按钮循环选择游戏类型和地图。布尔设置直接切换，其他设置填写值后点击对应行的“应用”。

该工具每次提交一个字段，适合在世界内快速调整。需要同时修改多个值时，地图详情页的设置页面会暂存多项改动并统一保存。

## 商店配置工具

物品 ID 为 `fpsmatch:shop_config_tool`。右键选择游戏类型和地图，再进入该地图支持编辑的队伍商店。只有已经具有并初始化 `ShopCapability` 的队伍会成为可编辑目标。

工具不会创建新的商店类型。地图使用的商品分类和槽位数量来自玩法模组；地图制作者负责填写已有槽位的商品、价格、数量和分组。

## 工具没有反应时

世界方块点击由客户端发送到服务端处理，创建和修改仍要求 OP 2。若服务器没有对应游戏类型、地图缺少能力、所选维度不一致或比赛正在进行，服务端会显示具体失败消息。

地图和队伍选择保存在工具自己的 NBT 中。复制工具也会复制当前选择；要操作另一张地图，请在工具界面重新选择目标，不要仅凭手中物品名称判断其目标。
