# 地图与玩法区域

区域由两个方块坐标描述，包括两个端点之间的整个三维空间。地图区域是最外层边界，爆破区和商店区则承担具体玩法规则。

## 从地图详情页进入

执行 `/fpsm mapselect`，打开 `training` 的详情页，进入“管理 → 区域编辑”。管理员可以选择：

- 地图区域：修改地图的总边界。
- 爆破区域：编辑已有安包区。
- 新爆破区域：为具有爆破能力的地图新增安包区。

坐标格式是三个整数 `x y z`。“当前位置”会读取玩家当前方块位置。点击“预览”后，服务端把地图区域和爆破区同步给当前玩家显示。

## 修改地图区域

选择“地图区域”，填写 `Pos1` 和 `Pos2` 后保存。服务器会拒绝比赛进行中的修改。如果地图已有爆破区，新边界必须继续完整包含所有爆破区；应先调整或删除越界区域，再缩小地图边界。

地图边界改变后，地图 ID、维度、设置、队伍、商店和装备不会重建。出生点不会由该操作自动移动，因此边界调整时要留意原有点位的位置关系。

## 添加和修改爆破区

选择“新爆破区域”，填写两个对角点并保存。爆破区必须完全位于地图区域内，当前实现每张地图最多保存 256 个爆破区。

编辑已有区域时，先在左侧选择它，再修改坐标。删除操作需要再次确认。服务端保存成功后会返回新的地图详情，列表中的索引也会随删除结果更新。

如果详情页显示“此地图不支持爆破区域”，说明当前地图没有 `DemolitionModeCapability`。普通死斗地图不会因为填写坐标而获得安包规则。

## 使用命令配置爆破区

新增区域：

```text
/fpsm map modify cs training capability demolition bomb_area add <from> <to>
```

显示当前爆破区域：

```text
/fpsm map modify cs training capability demolition bomb_area display
```

命令入口目前用于新增和显示。更新、删除以及地图边界修改使用详情页或地图创建工具更直接。

## 区分三类区域

地图区域决定玩家和地图对象所处的总体空间。爆破区决定爆破能力认可的安包空间。商店区属于某个队伍的商店能力，决定该队玩家可以打开商店的位置；它在[商店配置](shop.md)中管理。
