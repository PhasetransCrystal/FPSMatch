# 认识地图制作者工作流

FPSMatch 不复制或生成世界建筑。它在现有世界中保存一个三维区域，并把这个区域与某种玩法连接起来。建造场景、配置比赛和开发玩法是三种不同工作。

## 地图由什么组成

| 内容 | 示例 | 来源 |
| --- | --- | --- |
| 游戏类型 | `cs` | BlockOffensive 或其他玩法模组注册 |
| 地图 ID | `training` | 创建地图时填写，作为长期标识 |
| 所在维度 | `minecraft:overworld` | 创建时所处的服务端维度 |
| 地图区域 | 两个对角方块坐标 | 地图创建工具或区域编辑器 |
| 队伍 | 玩法定义的 T、CT 等 | 创建地图时由游戏类型工厂生成 |
| 能力 | 出生点、商店、爆破区等 | 由游戏类型附加到地图或队伍 |
| 设置 | 展示名、自动开始等 | 游戏类型注册，地图保存具体值 |

地图 ID 只能使用 1 至 48 位小写字母、数字、下划线和连字符。不要把中文标题写入 ID；玩家看到的名称使用 `displayName` 设置。

## 推荐的制作顺序

先完成世界建筑，再建立一个覆盖所有游玩空间的地图区域。地图创建后，按“出生点 → 目标区域 → 设置 → 装备 → 商店”的顺序配置，可以尽早确定队伍和空间关系。

地图边界是后续空间配置的外层约束。普通出生点和爆破区必须落在地图区域内；缩小已有边界时，如果爆破区会落到外面，服务端会拒绝修改。

## 图形界面与工具

地图详情页适合集中管理一张已有地图：设置页按分类展示字段，区域页编辑地图与爆破区，商店页进入队伍商店，导入页复用其他地图配置。

手持工具适合站在世界里取坐标：

| 工具 | 主要用途 |
| --- | --- |
| 地图创建工具 | 选择两个对角点，创建地图或更新边界 |
| 复活点工具 | 选择游戏类型、地图和队伍，在方块上方添加出生点 |
| 对局配置工具 | 快速切换地图并修改设置 |
| 商店配置工具 | 选择地图，进入已有队伍商店编辑器 |

这些工具的具体按键见[地图工具](tools.md)。

## 权限和运行状态

地图创建、区域修改、设置保存、商店编辑和比赛管理要求管理员权限。地图正在进行比赛时，区域和出生点编辑会被拒绝。先在房间管理页结束或清理当前比赛，再修改空间配置。

玩法模组决定某张地图有哪些队伍和能力。若界面没有“爆破区域”或“编辑商店”，通常表示当前地图没有相应能力，而不是按钮加载失败。
