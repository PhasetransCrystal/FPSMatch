# 房间与比赛管理

地图选择界面同时是玩家入口和管理员控制台。它显示每张地图的游戏类型、人数、状态和加入条件；地图详情页提供队伍、设置和比赛管理操作。

## 打开地图详情

客户端执行：

```text
/fpsm mapselect
```

列表可以按地图状态和游戏类型筛选。进入 `training` 的详情后，页面会持续订阅该房间的状态；玩家加入、队伍变化和比赛开始后，界面会收到更新，无需不断关闭重开。

普通玩家看到加入、离开、准备和允许的换队操作。拥有管理权限的玩家还会看到管理、邀请、设置、商店、区域、导入和比赛操作。

## 加入、准备和队伍

“进入大厅”让服务器为玩家选择可用普通队伍。加入后可以在未开始阶段切换允许的队伍并设置准备状态。旁观者不能准备；地图满员或禁止中途加入时，服务器会拒绝加入。

管理员可以把玩家移到某个普通队伍或旁观队伍，也可以将玩家移出地图。界面提交的是操作请求，最终结果仍由当前地图的容量和换队规则决定。

邀请只对尚未加入该地图的可用玩家开放。收到邀请的玩家可以接受或拒绝；地图消失、人数已满或邀请状态变化后，旧邀请可能失效。

## 比赛操作

管理页提供以下动作：

| 操作 | 作用 |
| --- | --- |
| 开始 | 调用地图的开始流程 |
| 重置 | 将地图恢复为玩法定义的重置状态 |
| 新回合 | 请求玩法开始下一回合 |
| 清理 | 调用地图清理流程，移除运行状态和临时对象 |
| 调试 | 切换地图调试模式 |

这些按钮与 `debug start`、`reset`、
ew_round`、`cleanup` 和 `switch` 命令对应。不同游戏类型对“新回合”和“清理”的具体处理可能不同；界面不会绕过玩法逻辑直接改分数。

## 使用命令管理

```text
/fpsm map modify cs training debug start
/fpsm map modify cs training debug new_round
/fpsm map modify cs training debug reset
/fpsm map modify cs training debug cleanup
/fpsm map modify cs training debug switch
```

加入或离开地图：

```text
/fpsm map modify cs training team join <targets>
/fpsm map modify cs training team leave <targets>
```

不写 `<targets>` 时作用于执行命令的玩家。命令方块或控制台不能使用这个省略形式，因为它们没有玩家身份。

## 修改配置时的状态限制

区域、出生点和部分管理员编辑只在地图未开始时开放。设置页是否允许修改某个字段由服务器返回的 `editable` 状态决定。需要改变空间配置时，先使用重置或清理动作让地图回到非运行状态。
