# 创建地图与边界

本章创建一张游戏类型为 `cs`、地图 ID 为 `training` 的地图。若服务器使用其他玩法，把 `cs` 换成创建界面列出的实际类型。

## 选择两个对角点

从创造模式物品栏的 FPSMatch 分类取得“地图创建工具”。手持工具时：

- 左键方块设置 `Pos1`。
- 右键方块设置 `Pos2`。
- `Ctrl + 右键` 打开地图创建界面。

两个点描述一个包含上下高度的长方体。把边界覆盖所有可到达路线、出生房间和目标区域；它不是只圈地面的二维选区。手持工具时，已完成的选区会作为世界预览显示。

创建界面左侧保留在屏幕上，可以直接点击面板外的方块：左键更新 `Pos1`，右键更新 `Pos2`。坐标也可以在输入框中精确修改。

## 创建 `training`

在界面中选择游戏类型 `cs`，在地图名称中填写 `training`，然后点击“创建地图”。服务端会使用该游戏类型的工厂创建地图、队伍、能力和默认设置，并立即保存数据。

“已有地图”选择器用于更新，不决定新地图的 ID。创建新地图时使用“地图名称”输入框；更新边界时选择已有地图并点击“保存地图”。创建成功后，工具会自动记住所选类型和地图。

同一游戏类型内不能存在重复地图 ID。不同类型的地图由类型和地图名共同定位，但仍建议在服务器范围内使用清楚且稳定的 ID。

## 使用命令创建

不使用工具时，可以直接给出两个方块坐标：

```text
/fpsm map create cs training 0 64 0 100 90 100
```

相对坐标也遵循 Minecraft 命令语法：

```text
/fpsm map create cs training ~-50 ~-10 ~-50 ~50 ~30 ~50
```

命令创建和工具创建都会建立完整地图对象并保存；它们不是两种不同地图格式。

## 修改已有边界

在地图创建工具中选择 `cs / training`，重新设置两个点并点击“保存地图”。更新要求：地图未开始、操作者位于地图所在维度，且已有爆破区仍完全位于新区域内。

也可以从地图详情页进入“区域编辑”，选择“地图区域”后填写两端坐标。详情页还提供“当前位置”按钮，将玩家所在方块写入对应端点。

地图 ID、游戏类型和维度不会随边界更新而改变。若需要把建筑作为另一种游戏类型使用，应新建另一张地图，再通过[导入配置](importing.md)复用兼容内容。
