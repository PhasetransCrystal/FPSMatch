FPSMatch 1.3.0 更新日志
基线：1.2.5（与 BlockOffensive 1.2.5.1 同期的 FPSMatch 最后提交，2025-10-15）
范围：截至 2026-09-16 的当前工作区快照

说明
- FPSMatch 1.2.5 没有独立的 1.2.5.1 标签；本文使用 2025-10-15 的 1.2.5 最后提交作为对应基线。
- 本文只记录最终工作区仍存在的玩家、服主、地图作者或玩法扩展者可感知变化。1.3.0 为源码工作区快照，不代表已经发布的公开构建。

新增与重做：地图房间和准备大厅
- 地图选择界面改为 Modern UI 实现，支持地图搜索，以及全部、等待中、进行中、可加入等状态筛选和模式筛选。
- 地图详情页可显示地图人数、状态、是否允许中途加入、队伍和准备情况，并支持进入/离开地图、邀请、管理和查看玩家。
- 新增实时房间状态同步：玩家加入、离开、队伍变化、准备状态和倒计时会同步到房间界面。
- 新增准备开始与自动开始策略；全员准备后可开始倒计时，旁观者不会被错误计入准备人数。
- 管理员可在队伍管理页移动玩家、换队或踢出当前地图；界面会显示队伍容量和旁观者列表。
- 地图卡片和详情页支持 displayName、iconTexture、backgroundTexture。地图图标/背景使用客户端资源位置，可由模组或资源包提供。

新增：地图制作与管理工具
- 地图创建工具和出生点工具改进了交互与校验。地图 ID 限制为 1-48 位的小写字母、数字、下划线或连字符；显示名可单独设置。
- 出生点会校验地图边界、维度、脚下支撑、两格净空、流体和重复点；对局进行时禁止修改地图边界或出生点。
- 新增区域编辑页：可编辑地图范围和爆破区，直接使用当前位置填写坐标、预览区域、新增/修改/删除爆破区，并阻止把爆破区放到地图外或在比赛中修改区域。
- 新增地图配置导入：可从同游戏类型的地图选择性导入地图设置、队伍商店和起始装备；导入前会展示覆盖内容并要求二次确认。
- 地图配置的读取、写入和迁移改用明确 UTF-8 与资源安全处理；旧版数据可以在加载时转换到当前格式。
- 保存流程增强：地图设置、出生点、起始装备和商店修改会持久化，服务器重启或手动 /fpsm save 后可恢复。

商店、经济与对局数据
- 重做管理员商店编辑器：可编辑槽位商品、价格、数量、虚拟弹药、分组和监听模块；可从手持物品复制商品样本。
- 商店编辑支持跨分类批量设置分组 ID、未保存修改提示、服务器端校验、超时保留输入及并发更新提示。
- 商店和队伍经济会在回合、队伍及地图状态变化时正确同步；未知商品类型和特殊余额值会安全处理，避免客户端菜单异常。
- 对局侧玩家数据与 HUD 统计得到扩展，包含 KDA、击杀、爆头、伤害、助攻判定等可供玩法和界面使用的信息。
- 拾取限制、掉落物和弹药/武器兼容处理更可靠，减少不同枪械提供者或物品类型导致的对局物品错误。

旁观、镜头与客户端表现
- 旁观系统补充环绕观战与枪械兼容表现；对 TacZ/LR Tactical 场景处理第一人称武器动画、换弹、开火、镜像物品和镜头后坐力。
- 新增统一镜头系统，玩法模组可用同一套镜头运行时和命令路由实现演出、观战或自定义相机流程。
- 客户端 HUD/队伍投影缓存与网络线程处理得到加强，在玩家较多或频繁同步时减少卡顿和显示不同步。

扩展与兼容
- FPSMatch 继续作为框架模组：具体游戏类型需要由 BlockOffensive、其他模组或 KubeJS 注册。当前组合工作区由 BlockOffensive 提供 cs 和 csdm。
- 增强 TaCZ 多提供者兼容抽象，避免把特定枪械实现硬编码为框架的唯一前提；CounterStrikeGrenade、LR Tactical、KubeJS 等继续按整合包需要选装。
- 增加 Mohist/Bukkit 事件桥接相关支持，混合服务端可将 FPSMatch 对局事件交给 Bukkit 插件处理。

开发者与 API
- Java 包名由 com.phasetranscrystal.fpsmatch 迁移为 com.ptcrys.fpsmatch。这是二进制不兼容迁移；附属模组、KubeJS Java 扩展、Bukkit 桥接和直接调用 API 的工程均须更新导入路径并按 1.3.0 重新编译。
- 游戏类型注册、保存数据、命令扩展和商店监听模块均提供注册事件：RegisterFPSMapEvent、RegisterFPSMSaveDataEvent、RegisterFPSMCommandEvent、RegisterListenerModuleEvent。玩法模组可注册自己的地图构造器和命令分支，而非修改 FPSMatch 的 /fpsm 根命令实现。
- 地图/队伍扩展继续围绕 MapCapability、TeamCapability 和 CapabilityMap。当前地图生命周期会发布 FPSMapEvent 的开始、胜利、清理、重置、重载、加载以及玩家进出、受伤、死亡、击杀、拾取、丢弃、聊天等事件；可取消的事件应由监听方自行处理被阻止后的玩法状态。
- FPSMapEvent.VictoryEvent 现在携带不可变的玩家计分快照和队伍汇总，可读取分数、KDA、助攻、伤害、爆头率和队伍回合分，方便统计、赛后页面或外部上报避免读取已被清理的实时地图对象。
- KubeJS 桥接覆盖地图开始/胜利/清理/重置、玩家加入/离开/受伤/死亡/击杀/登录/登出和队伍加入/离开事件。脚本应按当前事件名和载荷重新检查，特别是涉及击杀归因或地图重置的规则。
- 新增客户端镜头抽象：CameraDirector 管理会话，CameraRig、CameraPose、CameraPolicy 与 CameraSequence 用于组合固定、实体视角、轨道、路径和碰撞修正镜头。相机拥有者、输入拦截、生命周期结束原因和叠加层事件被集中处理，玩法模组可在此基础上实现演出或观战，不应与旁观 Mixin 直接竞争控制权。
- /fpsm 命令树由可扩展的帮助管理器统一生成；地图、能力和客户端命令可注册帮助与参数信息。命令扩展应从 RegisterFPSMCommandEvent 挂接，并通过 FPSMCommand 的地图/队伍/能力查询助手取得上下文。
- Bukkit/Mohist 桥接在检测到 Bukkit 环境后注册，提供地图击杀和比赛胜利事件。需要跨生态联动时应监听桥接事件或 Forge 原始事件，不应依赖内部反射探测。

修复与安全性
- 修复地图选择界面生命周期、房间状态包、队伍焦点选择、准备状态、加入/离开和权限反馈的多项问题。
- 修复网络包在错误线程处理、客户端/专用服务器 Mixin 装载、读写资源泄漏和无效配置导致的崩溃或状态不同步问题。
- 修复队伍商店数据相互覆盖、补偿经济、未知商店类型、地图编辑边界和地图导入校验等服主可见问题。
- 修复 TacZ 死亡标记、敌我发光可见性、投射物清理、枪械状态与旁观表现等兼容问题。

运行环境
- 当前源码工作区面向 Minecraft 1.20.1 / Forge 47.4.10 / Java 17；客户端界面使用 Modern UI 1.20.1-3.12.0.1，Kotlin for Forge 为框架依赖。
- Modern UI 负责地图、房间和商店的客户端界面渲染；纯专用服务器不需要为这些客户端页面单独安装界面模组。
