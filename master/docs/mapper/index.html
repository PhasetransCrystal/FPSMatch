地图制作者手册

地图制作者负责把已经注册的游戏类型配置成一张可玩的地图。你会定义地图边界、队伍出生点、目标区域、起始装备、商店和房间展示信息，不需要继承 BaseMap 或编写 Forge 模组。

本文档对应 Minecraft 1.20.1 的当前 FPSMatch 源码。你需要管理员权限等级 2，并安装至少一个提供游戏类型的模组。BlockOffensive 通常提供 cs 和 csdm；服务器实际可用类型以地图创建工具和命令补全为准。

从一张空地图开始​

第一次制作时，按下面的顺序阅读。每一章都继续配置同一张 training 地图：

  1. 认识地图制作者工作流：区分世界建筑、FPSMatch 地图和游戏类型。
  2. 创建地图与边界：使用地图创建工具建立第一张地图。
  3. 配置队伍和出生点：给玩法已有的队伍添加安全出生位置。
  4. 编辑玩法区域：调整地图边界并添加爆破区域。
  5. 修改地图设置：设置展示名称、加入规则和自动开始行为。
  6. 配置起始装备：分别定义每个队伍开局得到的物品。
  7. 配置商店：初始化商店、编辑商品和购买区域。
  8. 配置商店监听模块：设置退货、护甲升级和动态换物联动。
  9. 管理房间与比赛：通过地图详情页管理玩家和比赛状态。

地图工具与命令操作的是同一份服务端数据。可以用图形界面完成大部分配置，再用命令处理少量精确操作；无需在两套流程之间重复配置。

三个不能混用的名字​

cs 是游戏类型 ID，决定地图实例有哪些队伍、设置和能力。training 是地图 ID，在命令和存档中长期标识这张地图。训练场 是展示名称，可以在设置中修改和翻译。

游戏类型来自模组代码，地图制作者不能通过配置新增一种玩法。不同游戏类型即使使用相同建筑，也会生成不同的地图数据和命令路径。

管理入口​

打开地图选择界面使用客户端命令：

/fpsm mapselect

进入地图详情页后，管理员可以看到设置、商店、区域、配置导入和比赛操作。创造模式物品栏的 FPSMatch 分类还提供地图创建工具、复活点工具、对局配置工具和商店配置工具。

命令行入口统一位于 /fpsm map。执行 /fpsm help 会按当前服务器注册的玩法和能力生成命令树，因此扩展模组添加的内容也会显示在那里。
